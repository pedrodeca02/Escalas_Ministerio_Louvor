# Escalas_Ministerio_Louvor
Sistema para organização das escalas do Ministério de Louvor, permitindo visualizar membros, funções, indisponibilidades e montar escalas por data.  O projeto utiliza HTML no front-end e Spring Boot com JPA e MySQL no back-end, com validação para impedir que membros indisponíveis sejam adicionados à escala.
